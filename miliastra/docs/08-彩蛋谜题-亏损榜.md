# 彩蛋谜题：「十人坠崖」——去原奇域找那张榜

> 来源：奇匠讲的真事 —— 原《璃月黄金交易所》里作者**忘了加限制**，
> 做空黄金后"用等量黄金价值的现金还金"能**疯狂向服务器发包**，数值被刷到离谱。
> 奇匠当时是那张**亏损榜**上的**第 9 名（凝銘）**。
> ★ 本版按奇匠要求：数字**不藏在关卡里** ✓，而是让玩家**自己去原奇域看排行榜** ✓。

## 一、门禁（点「◈ 交易所」先看到这一屏）

只给**谜面 + 输入 + 键盘**，一个数字都没有：

    璃月黄金交易所 · 门禁

        十人坠崖，皆是赌徒。
        榜不在我，榜在人间。
        合而为一，去其零头。
        无正无负，方入此门。

    输入： _ _ _ _ _ _            [1..9] [清除] [0] [确认]

### 谜面逐句（**这张表不显示给玩家**）

| 谜面 | 意思 |
|---|---|
| 十人坠崖，皆是赌徒 | 那张亏损榜的十个人 |
| **榜不在我，榜在人间** | **别在本彩蛋里找** ⇒ 去**原奇域《璃月黄金交易所》**里翻它的**排行榜** |
| 合而为一 | 十个数**加起来** |
| 去其零头 | **四舍五入取整**（先合后取整 ✓ 不是先截尾 ✗） |
| 无正无负 | 输入**不带负号** |

## 二、十个数字从哪来（**我们不存这些数据** ✓）

- 来源 = **原奇域《璃月黄金交易所》的排行榜（亏损榜）** ✓
- 也就是奇匠提供的那张截图（本文件末尾附一份，作为**取数基准** ✓）
- ⇒ 本项目**不在关卡/结算里埋任何数字** ✓（上一版方案已废弃 ✗）

## 三、密码 = **599499**

| 算法 | 结果 |
|---|---|
| 十个数逐项相加 | -599499.09 |
| **四舍五入取整** | **599499** ✓ ← 密码 |
| 先截尾再加 | 599493 ✗（谜面是"合而为一，去其零头"= 先合后去 ✓）|

### ⚠ 必须知道的风险：这个榜是"活的"

- 玩家还在原奇域里继续亏 ⇒ 榜上的数字会**一直变** ✗ ⇒ 固定密码 **599499 会漂** ✓
- 本项目**读不到那个榜**（脚本没有跨奇域/联网能力 ✗）⇒ 门禁**只能验一个固定值** ✗
- 处理办法（两条同时做 ✓）：
  1. **把密码锚在"那一刻"**：谜面写「榜在人间」即可 ✓，密码以**本文件附的截图**为准 ✓；
     若日后榜变了想跟，就**改 `M.LOCK_CODE` 一个常量**即可 ✓
  2. **保底可解**（防"榜变了/奇域没了/找不到"导致彻底卡死 ✗）：
     输错 **3 次**后，门禁**直接把十行数字列出来** ✓，谜面那句改成
     「十人皆在此，合之去零头」✓ ⇒ 玩家照样能自己算出来 ✓

## 四、输入与判定

- 键盘 `1 2 3 / 4 5 6 / 7 8 9 / 清除 0 确认` ✓
  **复用菜单 12 个按钮池** ✓（门禁屏菜单不可见 ⇒ **零新控件** ✓）
- ⚠ 必须 `SetAsLastSibling` 提到最上层 ✓（被暗幕压住这个 bug 踩过一次 ✓）
- 输满 6 位自动判 ✓；错 ⇒ 输入行变红清空 ✓；连错 3 次 ⇒ 出保底十行 ✓
- 输对 ⇒ `screen='egg'` ✓ + `G.eggUnlocked = true` ✓（本局内不再问 ✓）

## 五、实现清单

| 文件 | 改动 |
|---|---|
| `egg.lua` | 只加 `M.LOCK_CODE = 599499` ✓。**不存十人数据** —— 只在注释里写下算法与"榜会漂、要改就改这一个常量"✓ |
| `game.lua` | ① 点「◈ 交易所」⇒ `screen='lock'`（已解锁直接 `'egg'`）② `lock` 屏 12 键位点击 ③ `G.lockInput` / `G.lockTries` |
| `ui.lua` | `syncLock`：谜面 4 行 + 输入行 + 12 键（复用菜单池 + `SetAsLastSibling`）；连错 3 次后换成十行数字（用 `e.lines` ⇒ **5 扩到 12** ✓ +7 ⇒ 924/1000 ✓）|
| 文案 | 谜面四句照抄 ✓；解锁后交易所里多一行「第 9 名 —— 纪念那个疯狂发包的下午。」✓ |

## 六、明确不做

- **不在关卡/结算里埋数字** ✗（本版明确不要 ✓）
- 不做真的"发网络包" ✗（致敬的是**规则漏检**这个逻辑漏洞 ✓）
- 不破坏正常玩法与对拍 ✓（门禁只在彩蛋入口 ✓）
