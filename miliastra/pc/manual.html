第 2 步 · 在千星沙箱里建"空壳"

官方术语照着抄，别自己猜名字（括号里是官方文档里的原词）：

2.1 建客户端控件容器（= 画布，必须有）

  1. 打开千星沙箱，进到你的关卡。
  2. 找到客户端控件相关入口，新增客户端控件容器，然后编辑客户端控件容器画布。
  3. ⚠ 不要把东西放在"主屏"里 —— 主屏里的控件不能被脚本动态创建，会直接失败。
⚠ 两个"容器"名字很像，别搞混（这是最容易绕晕的一处）
名字是什么要不要画布
客户端控件容器 就是"画布"本身（服务器控件）。客户端控件靠它才能在主屏显示；脚本也必须有它才有地方挂 ✅ 必须有 —— 它本身就是画布
容器节点控件 一个普通控件模板（就是下面表里的 ④），被脚本当作"玩区父节点"用 ❌ 和画布无关，可以不建（脚本会自动改用画布自带的默认容器节点）

2.2 建客户端控件模板（一个都不需要画布）

4 个模板都在同一个地方建，而且不需要画布：

控件组管理 → 界面控件组库 → 客户端控件模板 → 【添加客户端控件】 → 选类型 → 存为模板

（另一条路"从客户端控件容器进去、在画布里加控件"也能建，但那是在关卡里摆实例； 脚本动态创建要的是存为模板，所以走上面这条最直接。官方文档 §二 把这两条入口分开写了。）

必建？建什么干什么用
必须图片控件球 / 弹药 / 连线 / 轨道 / 洞穴 / 光晕（都是一个模板拉长放大出来的）
必须文本框控件分数 / 命 / 提示 / 诊断行 / 球面碱基字母
必须光标检测区域控件接鼠标点击（瞄准开火）。类型必须是它，别的类型收不到点击
可省容器节点控件玩区父节点。不建的话脚本直接用画布的默认容器节点当父节点

尺寸随意 —— 脚本运行时会自己设。索引也不用抄：脚本用官方 typeof() 自动认 （见第 4 步）。⚠ 但类型不能拿别的凑：光标检测区域必须是光标检测区域，文本框必须是文本框 （脚本会当场检查并报错，不然到真机上会崩在"调用不存在的方法"上）。

★ 图片模板必须有一张"白圆图"，而且要把资产号告诉脚本
真机实测（2026-09-25）：动态创建出来的图片控件不会继承模板/画布上配的那张图 —— 脚本必须自己调 SetImage(图片来源, 资产号)，不调就全画成"?" （表现：球是一个个问号、轨道是一堆问号拼的、中央一个大问号）。

⚠ 两个数字别搞混：
名字长什么样用在哪
控件模板索引大数字，如 1073741852 脚本变量 ballPrefab 等（而且脚本会自动认，不用填）
资产号（素材 id）小数字，如 100002 SetImage 用 —— 脚本三个默认值都填好了（见下表），照默认做就什么都不用填
需要两张图（都可从素材库里找/自己传）：
用在哪要什么形状脚本变量
球面、光晕、核糖体、背板纯白实心圆artImage=资产号（默认 100002）
轨道 / 配对连线 / 瞄准线（拉成长条） 纯白正方形（越小越好，直角、无描边；圆图拉长会鼓出来） artBar=资产号（默认 100001）
洞穴那几圈红环纯白空心圆artRing=资产号（默认 100006）
换图就填脚本变量 artImage=你的资产号；想 5 种碱基各一张图就 art=A:资产号,U:…,G:…,C:…,T:…。
（脚本也会先在画布里找一张配好图的图片控件来"借"它的资产号；实在没有就用默认的 100002。）

第 3 步 · 让脚本找到那个下载下来的文件

官方说法是"脚本需要与本地文件关联"。两种做法，先试方式 1（云电脑上方式 2 常报"不允许访问"）：

方式 1（推荐）：新建客户端脚本，让编辑器自己建文件

  1. 进客户端脚本资源管理器，右键空白处 → 新建客户端脚本。
  2. 它会自己在游戏目录里建好那个 lua 文件（你不需要去 AppData 里挑文件）。
  3. 用记事本/VS Code 打开桌面上那个 1_先上这个_hello.lua，全选复制， 再打开编辑器建出来的那个文件，全选粘贴覆盖，保存。（或者直接把桌面文件复制过去覆盖同名文件。）
  4. 回到画布的脚本页签 → 添加脚本 → 选它。然后去第 5 步试玩。

⚠ 别在网页/记事本里"看着差不多"就少复制几行 —— lua 少一行不一定报错，可能只是"跑起来怪怪的"。

方式 2（方式 1 里没这个菜单时才用）：新建脚本映射 → 选本地文件

  1. 进客户端脚本资源管理器 → 客户端脚本映射文件夹。
  2. 右键 → 新建脚本映射。
  3. 右键它 → 编辑脚本映射路径 → 选择与脚本映射关联的本地文件 → 选桌面上的 1_先上这个_hello.lua。
  4. 回到第 2.3 步的脚本页签，添加脚本，选刚建的这个映射。
  5. 如果这一步弹"不允许访问 … external_lua_file" → 不是你的错，看下面的方式 3。

方式 3（云电脑上实测有效）：让 DSH 直接把文件放进去

实测：那个目录本身是可写的（报"不允许访问"的是对话框，不是权限）。所以回 DSH 说一句 "把脚本放进游戏目录"，它会跑 node miliastra/tools/pc-install-scripts.mjs， 把 hello.lua + zuma.lua 直接拷进：

C:\Users\<用户名>\AppData\LocalLow\miHoYo\原神\BeyondLocal\<UID>\Beyond_Local_Save_Level\<关卡ID>\external_lua_file

放好之后再进"选择与脚本映射关联的本地文件"，把这个路径粘到对话框地址栏， 应该就能看到 hello.lua 了。⚠ 云电脑重启会清空这个目录，回来让 DSH 再放一次即可。

⚠ 这一步是"必须建立映射"
官方原话："只有在千星沙箱里建立了映射的 lua 文件才会被打包上传"。 只把文件放本地、没建映射，试玩时脚本根本不会跑 —— 表现就是"一片空白，啥也没有"。

第 4 步 · 填脚本变量（★ 现在一个都不用填）

★ 模板索引不用你抄：脚本自己认
脚本在启动时会用官方 typeof()（"返回运行时类型名称"）挨个试一遍模板索引， 认出来是图片/文本框/光标检测区域/容器的就是它 —— 探针用完立刻销毁，不占控件数。
所以这一页可以整页跳过。日志里会打一行 [zuma] 用这套模板索引：球=… 弹药=… 文本=… 光标=… 玩区=…，你可以顺手核对一下。

下面这张表只在两种情况下才需要填：① 自动认错了（比如你建了两个图片控件）； ② 你想手动指定。进客户端脚本资源管理器 → 右键那个客户端脚本 → 编辑脚本变量。 索引从哪看：在编辑器里点一下那个控件，界面上会显示它的"控件模板索引"（一个很大的数字，形如 1073741xxx）。

变量名填什么默认
levelIndex从第几关开始，1 = ① 配对（最简单）1
autoPrefabs自动认控件模板（保持 1 就别管下面的索引了）1
ballPrefab球控件的模板索引（留空 = 自动认）自动
hudPrefab文本框控件的模板索引（留空 = 自动认）自动
cursorPrefab光标检测区域控件的模板索引（留空 = 自动认）自动
playPrefab容器节点控件的模板索引（留空 = 自动认）自动
shotPrefab弹药控件模板索引（不填就跟球一样）= ballPrefab
ballCount球池大小，先小一点好排错96
shotCount弹药池大小8
fancy光晕 / 冷却环 / 动效。哪样看着不对就先设 0，只剩静态画面1
track轨道由脚本自己画（一段段拼出来）；设 0 就用你在编辑器里摆的轨道图1
trackSegments每条轨画多少段。卡就调小（32）64
letters球面上的碱基字母（A/U/G/C/T）由脚本叠文本框；素材图自带字母就设 01
seed随机种子，换个数就是另一局12345
autoNext过关自动下一关，0 = 不自动1
diag屏幕左下角那行诊断字，排错时别关；正式发布再设 01
控件数与素材：两张图就够
控件数：脚本建多少控件 ≈ 7.7 × ballCount（ballCount=96 时约 740 个；平台上限是单控件组 1000）。 感觉卡就把 trackSegments 调到 32，或者 track=0 / letters=0。
素材：模板① 那张图片最好是纯白的圆（不要带描边、不要带字母）—— 脚本会给它上色，还会把它拉长当瞄准线 / 配对连线 / 轨道路面用。 圆球模板拉长后是"两端圆头的棒"，正合适。
轨道：track=1（默认）时轨道由脚本画，编辑器里不放轨道图也行； 想要更好的美术效果就自己摆一张轨道图，然后把 track 设 0。
那行诊断字是干什么的
我在你手机上，看不到你的屏幕。左下角那行会显示 帧/关卡/球数/控件数/状态；一旦出错会变成 !! 具体原因。 出问题时把那行字念给我，我就知道卡在哪一步了。

第 5 步 · 试玩

★ 第一次试玩：把 levelIndex 填 8，别用默认的 1
第 1 关（t1-pair）是静止练习关：按设计就是"没有轨道运动、只有 12 颗静止的球 + 一句提示"。 拿它当第一印象会觉得"好空、效果不行" —— 这是设计，不是移植问题。
填 levelIndex=8（spiral-outer）：大螺旋 + 48 颗球，一眼就是网页版那个样子。 想逐个看：1~7 是新手关（7 = 综合），8~11 是螺旋 / 交叉桥 / 无尽。
★ 画布建议接近方形（对观感影响很大）
游戏按 base = min(画布宽, 画布高) 适配：宽画布会让游戏只占中间一块、球也偏小。 实测这台机器画布是 1815×900（2:1），左右各空出一大片。
把客户端控件容器的画布改成方形（例如 1080×1080）：球直径 38→46px、轨道半径 405→486，几乎铺满。
  1. 保存，点试玩。
  2. 应该看到：轨道 + 一排带字母的球 + 屏幕中央的炮台（核糖体）+ 瞄准线 + 左上角"分数 0"。
  3. 鼠标移动 = 瞄准，按住左键 = 连发。
  4. Tab 切模式（配对 / 加球），空格 换手里那颗，R 重开本关。
★ 想让画面（球/轨道）更大：首选改画布尺寸，而不是改脚本
游戏尺寸按 scale = max(base/900, min(0.82, base/450))（base = min(画布宽,画布高)）算， 所以画布越大、球越大，而且两边（网页版/移植版）算出来一模一样：
画布scale大球 R小球 r屏幕直径
1815×900（当前）1.00019.013.438 : 27
1280×1280（推荐）1.42227.019.154 : 38
1440×14401.60030.421.561 : 43
1280×1280 正好是"大球 2 : 小球 √2"那一档（R 19→27 = ×√2，r 13.4→19.1 = 原来的大球）。
备选：不想动画布就填脚本变量 zoom=1.4222（等比放大 rx/ry/scale， R/r 仍是 √2、规则数值一个没动；这个旋钮本体没有，所以默认 1）。

专节 · 报错里出现 external_lua_file

完整路径长这样： C:\Users\<你的用户名>\AppData\LocalLow\miHoYo\原神\BeyondLocal\<UID>\Beyond_Local_Save_Level\<关卡ID>\external_lua_file

这是千星沙箱放"外部 lua 文件"的地方，在关卡存档目录里。官方文档（219 篇）里完全没提这个路径， 所以它是沙箱自己的实现。看到"不允许访问"，先分清是哪一种：

现象含义怎么办
资源管理器里点这个路径，Windows 说"拒绝访问" 这台机器**在系统层面**不让你读这个目录 见下面 A
千星沙箱里选文件时报"不允许访问" 沙箱**写不进**这个目录（它要把你选的 lua 复制进去） 见下面 B

A · 资源管理器都进不去

  1. 地址栏直接粘 %USERPROFILE%\AppData\LocalLow\miHoYo 回车（AppData 是隐藏目录，手点容易点不到）
  2. 还是拒绝 -> 开 PowerShell，粘这一行，看它怎么说：

    New-Item -ItemType Directory -Force "$env:USERPROFILE\AppData\LocalLow\miHoYo\原神\BeyondLocal\<UID>\Beyond_Local_Save_Level\<关卡ID>\external_lua_file"

  3. 报"拒绝访问" -> 是这台云电脑的限制，不是你操作错了。 云游戏机器常常把游戏存档目录锁住。三条出路：
    • 找云电脑客户端的"文件上传 / 文件管理"功能，用它把 lua 推进去；
    • 换一台机器（真机 / 别的云电脑）；
    • 把这段报错原文发我，我去查官方有没有别的入口。

B · 沙箱写不进去

  1. 先改用"新建客户端脚本"（官方文档里的第二种做法）： 客户端脚本资源管理器 → 右键 → 新建客户端脚本 → 它会自己在你指定的文件夹里建好文件。 这样就不需要你去那个目录里挑文件了。
  2. 建好之后，用资源管理器把 zuma.lua 的内容覆盖进那个文件（或者干脆把 zuma.lua 复制进同一个文件夹，再在映射里改选它）。
  3. 如果"新建客户端脚本"也报同样的错 -> 就是这台机器不让写那个目录，回到 A 的第 3 条。
顺手看一眼就知道的事
去那个 external_lua_file 文件夹里看看有没有文件： 官方文档说"本地日志的路径和客户端脚本的储存路径一致"，所以那里面可能已经有 ErrorLog.txt。 有文件 = 沙箱自己写得进去，那问题就只是"选文件"这个对话框，用 B 的第 1 条绕开就行。

想调什么

  • 换关卡：levelIndex 填 1~11（1~7 是新手关，8~11 是螺旋/交叉桥/无尽）。
  • 球太多/太少：ballCount。
  • 要改规则、改数值、加关卡：不要在编辑器里改（那改不动，逻辑在脚本里）。 回手机上跟我说就行 —— 源码在 miliastra/lua/src/，改完重新打包只要一条命令。
