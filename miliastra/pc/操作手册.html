电脑端操作手册 · 祖玛 · 千星奇域移植

给你（人）看的，不是给程序看的。左边手机在跑代码，这台电脑在跑编辑器，手册就是中间那根线。

先记住一句话
你要做的事只有一件：把 zuma.lua 这个文件，挂到编辑器里一个客户端控件上，然后试玩。 其它全是细节。

第 0 步 · 你现在手上有什么

  • 手机上有一个整包脚本 zuma.lua（约 86 KB，14 个模块打成一个文件）—— 这就是要上传的东西。
  • 它里面已经有：轨道数学、消球规则、画面同步、输入、11 个关卡数据。编辑器里不需要再写任何逻辑，只需要摆几个"空壳控件"。

第 1 步 · 把 zuma.lua 弄到这台电脑上

方式 A（最省事，推荐先试）：直接下载

手机上我已经开好了下载服务。在同一 WiFi 下，用这台电脑的浏览器打开：

下载 zuma.lua 打开这个文件夹

如果打不开，说明电脑和手机不在同一个 WiFi（或者机房 WiFi 开了"客户端隔离"）。 那就回到手机上跟 DSH 说一句"开隧道"，它会给你一个公网网址，用那个网址再下载一次。

方式 B：从 GitHub 拿

仓库是 ihamn/zuma。文件在 miliastra/out/zuma.lua，点 Raw 就能另存为。

⚠ 千万别"打开 zuma.lua 直接复制内容粘贴"
86 KB 手粘很容易缺一段，而且缺了对不齐的地方不会报错，只会"跑起来怪怪的"。 要的是一个真的文件，所以用下载 / 另存为。

第 2 步 · 在千星沙箱里建"空壳"

官方术语照着抄，别自己猜名字（括号里是官方文档里的原词）：

2.1 建客户端控件容器画布

  1. 打开千星沙箱，进到你的关卡。
  2. 找到客户端控件相关入口，新增客户端控件容器，然后编辑客户端控件容器画布。
  3. ⚠ 不要把东西放在"主屏"里 —— 主屏里的控件不能被脚本动态创建，会直接失败。

2.2 建 4 个客户端控件模板

在画布里创建客户端控件，建这 4 个，每个都存为模板，然后记下它的控件模板索引（一个数字，后面要填）：

序号建什么干什么用建议尺寸
①图片控件一颗球（也是弹药、玩区容器的模板）圆形，别设死尺寸，脚本会改
②文本框控件分数 / 命 / 提示 / 诊断行随意，脚本会改
③光标检测区域控件接鼠标点击（瞄准开火）随意，脚本会铺满
④容器节点控件玩区容器（所有东西挂在它下面）随意，脚本会铺满

③④ 嫌麻烦可以先不建：脚本允许它们复用 ① 的模板索引（下面变量表里有写默认值）。但光标检测区域建议单独建，不然点击可能收不到。

2.3 把脚本挂上去

  1. 在画布里建一个控件（就用 ① 的模板），它就是你脚本的挂载点。
  2. 选中它，打开脚本页签，点添加脚本。

第 3 步 · 让脚本找到那个下载下来的文件

官方说法是"脚本需要与本地文件关联"：

  1. 进客户端脚本资源管理器 → 客户端脚本映射文件夹。
  2. 右键 → 新建脚本映射。
  3. 右键它 → 编辑脚本映射路径 → 选择与脚本映射关联的本地文件 → 选第 1 步下载的那个 zuma.lua。
  4. 回到第 2.3 步的脚本页签，添加脚本，选刚建的这个映射。
⚠ 这一步是"必须建立映射"
官方原话："只有在千星沙箱里建立了映射的 lua 文件才会被打包上传"。 只把文件放本地、没建映射，试玩时脚本根本不会跑 —— 表现就是"一片空白，啥也没有"。

第 4 步 · 填脚本变量（就这一张表）

进客户端脚本资源管理器 → 右键那个客户端脚本 → 编辑脚本变量。按表填，不填的会用括号里的默认值：

变量名填什么默认
levelIndex从第几关开始，1 = ① 配对（最简单）1
ballPrefab模板① 的控件模板索引1
hudPrefab模板② 的控件模板索引2
cursorPrefab模板③ 的控件模板索引3
playPrefab模板④ 的控件模板索引（不建就填① 的）= ballPrefab
shotPrefab弹药控件模板索引（不建就填① 的）= ballPrefab
ballCount球池大小，先小一点好排错96
shotCount弹药池大小8
seed随机种子，换个数就是另一局12345
autoNext过关自动下一关，0 = 不自动1
diag屏幕左下角那行诊断字，排错时别关；正式发布再设 01
那行诊断字是干什么的
我在你手机上，看不到你的屏幕。左下角那行会显示 帧/关卡/球数/控件数/状态；一旦出错会变成 !! 具体原因。 出问题时把那行字念给我，我就知道卡在哪一步了。

第 5 步 · 试玩

  1. 保存，点试玩。
  2. 应该看到：一排彩色的球、左上角"分数 0"、右上角"命 3"、底部是这一关的说明。
  3. 鼠标移动 = 瞄准，按住左键 = 连发。
  4. Tab 切模式（配对 / 加球），空格 换手里那颗，R 重开本关。

第 6 步 · 出问题怎么办（对号入座）

你看到的大概是什么怎么办
一片空白，诊断行也没有脚本没跑起来脚本映射没建 / 没在脚本页签里添加 / 挂在了主屏上
诊断行写 !! 找不到挂载控件…挂载点不对把脚本挂到客户端控件上，别挂主屏
!! 球控件创建失败…模板索引没填 / 索引填错 / 这个控件不能动态创建核对 ballPrefab；控件别放在主屏、别放在模板控件的子节点下
!! 创建光标检测区域失败…cursorPrefab 不对改填模板③的索引
有球，但鼠标点了没反应点击没落到光标检测区域上确认按了鼠标左键；确认模板③是个"光标检测区域"控件
球都挤在中间 / 位置很怪画布尺寸和预期不一样把那行诊断字念给我，我据此改坐标换算
卡得厉害控件太多把 ballCount 调到 48 试试，并告诉我帧率感觉

想调什么

  • 换关卡：levelIndex 填 1~11（1~7 是新手关，8~11 是螺旋/交叉桥/无尽）。
  • 球太多/太少：ballCount。
  • 要改规则、改数值、加关卡：不要在编辑器里改（那改不动，逻辑在脚本里）。 回手机上跟我说就行 —— 源码在 miliastra/lua/src/，改完重新打包只要一条命令。
