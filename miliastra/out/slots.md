# 槽位表（移植用：路点与槽位一一对齐）

由 miliastra/tools/export-slots.mjs 生成，**不要手改**。

## 为什么是槽位

官方路径 = 路点折线 + 逐段到达时长，**没有进度/弧长读数**（见 docs/01）。
本作的绳模型建立在弧长 wp 上，搬不过去。移植方案改成：

1. 在编辑器里建一条路径，**路点间距 = 球距 p**（一个个摆，或用 slots.json 的坐标）；
2. 每个路点就是一个**槽位**，序号 0 = 出球口；
3. 每颗球记一个"槽位号"变量，位置由槽位号决定；
4. **前进** = 全体槽位号 +1（一个全局计时器驱动）；
5. **消除** = 把被消球之后那些球的槽位号往前挪 k 格（这就是"回缩"的离散版）。
