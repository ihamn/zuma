# 移植参数表（照抄到千星奇域编辑器用）

由 miliastra/tools/export-params.mjs 生成，**不要手改**。

没有列进这张表的常量（渲染配色、调试开关之类）不需要移植。

⚠ 两条**必须一起看**的话：

- **冒球率 = chainSpeed / 球距 p** —— 想改难度就改这两个的比值，单改一个会连带改动另一件事；
- **静置到洞穴的时间 = 轨道长 / chainSpeed** —— 这就是玩家不做任何事时的时限。
